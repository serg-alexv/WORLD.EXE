# WORLD.EXE

Scientific spatial exploration game for LiDAR-equipped iOS devices.

Genesis: ARKit scene reconstruction + RoomPlan scanning, with an original science-fantasy setting inspired by tactical strategy, open-world exploration, orbital engineering and grimdark fiction.

## Status
Initial repository bootstrap. iOS build is not yet verified; TestFlight is not yet published.
