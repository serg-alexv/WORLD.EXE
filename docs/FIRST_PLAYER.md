# WORLD.EXE — first outside-player test

**Status: public TestFlight admission has not yet been verified.** A public invite will be added here only after Apple's external-testing requirements are satisfied. An internal invitation or a GitHub binary is not a public TestFlight release.

## What this demo is
An experimental science-fiction playground: turn-based Signal Siege, two-person CONTACT, optional real room scanning/AR, optional local Qwen NPC dialogue, and a separately gated personal-feed demo. Gameplay works without LiDAR, imported personal data or downloading a language model.

The first test is simple: **play one mission, then tell us what happened**. Honest criticism is welcome. No positive rating, account signup or purchase is requested.

## First play
1. Open WORLD.EXE -> Expeditions (Экспедиции) -> Signal Siege.
2. Select a tile, inspect the route and confirm Move. Each turn has four action points. Walls block routes and line of sight. Watch the next hazard row and the sentry's forecast.
3. Secure relay R, return to extraction E and extract. Try Replay or the alternate difficulty. The trophy opens the local Top 10 for the same seed/difficulty.
4. Kira's tone can be neutral, sarcastic or dark. Without a loaded GGUF, the app uses explicitly scripted dialogue. Optional GGUF is a separate download/import and not required to finish the mission.

Optional: CONTACT is a separate cooperative mission. One-screen demonstration is available; two-device play uses explicit nearby pairing. Real sensor modes require supported hardware and camera permission. Do not walk into obstacles while looking at the screen.

Personal Feed -> Open demonstration uses fictional records. Live Hornet/Grindr integration is not available. For this public playtest, do not import sensitive real histories; that is outside the first-play task.

## Send the first review
Open TestFlight -> WORLD.EXE -> Send Beta Feedback. Include the build number and three plain answers:
- What did you think you were supposed to do?
- Where did you get stuck, confused or surprised?
- Would you voluntarily play another mission, and why or why not?

A screenshot of the fictional game is useful; remove any private content. This is beta feedback, not an App Store star rating. An install or crash alone is not counted as the first written player review. Apple reviewer approval, automated tests, developer self-tests and model-generated comments are also not a player's review.

## What is deliberately not promised
No cloud/global leaderboard; no certified sensor accuracy; no through-wall sensing; no live Hornet account connector; no OS-level isolation between modules in this combined app. Device performance, thermal behavior, two-phone reliability and the fun of the game need actual human testing.
